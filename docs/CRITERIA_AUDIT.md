## Воспроизведение

1. `python -m unittest discover -s tests -v` — ядро, сквозной маршрут, HTTP-роли и эмулятор.
2. `python -m qc.demo` — UI с эталоном 3 проверенных, 2 с подтверждённым несоответствием, 1 без пригодного контроля; I-004 имеет пропущенную пригодную контрольную точку.
3. `node tests/browser_smoke.js` при доступных Playwright/Chrome и токенах — обзор линии, I-003/I-004, действие контролёра, перерасчёт, ACK и мобильная ширина.

Доказательство ограничено локальными синтетическими событиями и перечисленными проверками. Максимальное соответствие критериям **не подтверждено**.
